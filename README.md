# NIM-Agent (Patched Claude Code)

A high-performance, community-patched distribution of Claude Code (via OpenClaude) hardcoded for **NVIDIA NIM** backend infrastructure. 

## Key Features
- **NIM-First Onboarding**: Optimized setup flow defaulting to NVIDIA NIM.
- **Agentic Recommendations**: Built-in tagging for the best coding and agentic models (Qwen 3 Coder 480B, Llama 3.1 405B).
- **Free Inference**: Guided instructions for obtaining free NVIDIA NIM API keys embedded in the CLI.
